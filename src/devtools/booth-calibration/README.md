# 展位边界校对工具

这是一个不接入正式应用入口的开发工具，用于基于固定底图校对展位矩形边界。

## 使用方式

在仓库根目录启动开发服务器：

```sh
vp run dev
```

打开：

```text
http://127.0.0.1:5173/src/devtools/booth-calibration/
```

可通过 `?hall=W5` 指定初始展馆。工具从 `src/data/exhibition.ts` 读取展位和坐标，只在浏览器本地保存校对草稿，不直接改写源码。完成后复制或下载坐标 JSON，再将确认过的值回填到数据文件。

方向键移动当前展位 1 像素，按住 Shift 时移动 5 像素；Command/Ctrl + Z 撤销，Command/Ctrl + Shift + Z 重做。拖动展位框可移动，拖动边缘或四角控制点可调整范围。点击底图空白处、按 Esc 或点击“取消选中”可移除橙色选中态。“显示覆盖层”开关可临时隐藏全部展位框、编号和控制点，以便直接观察底图边缘；再次打开不会丢失校对草稿。

## 移除方式

正式应用、生产构建和 Android 工程均不引用本目录。W1—W5 数据稳定后，删除整个 `src/devtools/booth-calibration/` 目录即可移除工具。
