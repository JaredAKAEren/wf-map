# W1 个人展商校对工具

这是一个不接入正式应用入口的开发工具。默认按原图列展示目前核出的 620 条编号和当前名称。全量人工校对结果已回填：619 条标记为“已核对”，`W1-B4-03` 标记为“看不清”并保留空名称。后续发现错误时仍可逐列修改。

## 使用方式

在仓库根目录启动开发服务器：

```sh
vp run dev
```

打开：

```text
http://127.0.0.1:5173/src/devtools/exhibitor-review/
```

工具优先读取以下本机文件，它们位于 `.gitignore` 忽略的目录，不会进入源码、Web 构建或 Android 包：

```text
.local/exhibitor-review/w1-1.png
.local/exhibitor-review/w1-2.png
.local/exhibitor-review/w1-3.png
.local/exhibitor-review/w1-4.png
```

本机没有这些文件时，可在页面顶部为四个来源分别选择原图。页面只创建浏览器本地 URL，不上传图片。

逐列视图把原图的一列与对应编号、名称按行对齐。核完一列后点击“确认本列已核对”，会确认该列尚待核对且有名称的记录；标记“看不清”的条目继续待处理。需要放大时点击该行“放大”，逐条视图会显示原图局部裁片和存在时的官网近似项。官网只作为辅助证据，最终以原图为准。裁片中的图片可直接拖动，也可用方向按钮逐次微调 2px；每个展位的偏移独立保存。

校对文本、确认状态、当前列和裁片偏移都保存在当前页面来源的浏览器 `localStorage`，同一地址刷新后会自动恢复。新版本会读取旧版本在同一地址保存的进度；本次 620 条人工校对状态也保存在 `reviewed-decisions.ts` 中。更换端口、浏览器或清理站点数据时不会共享后续进度，因此后续校对仍应阶段性下载 JSON 备份，再用“导入 JSON”恢复。JSON 导出包含全部 620 条记录及各自状态，旧版 102 条 JSON 也可导入；后续修正结果再回填至 `src/data/exhibition/w1.ts`。

## 数据范围

- 原图目前核出 620 行个人展商编号；先前漏掉的 `W1-B5-01`、`W1-D3-09` 和 `W1-G2-08` 已补录，误列的 `W1-H1-13` 已移除。
- `review-data.ts` 维护原图列与编号对应关系及官网近似项，不保存完整官网名单。
- `reviewed-decisions.ts` 记录本次 620 个编号的人工校对状态和名称；只有名称与当前源码一致时才恢复“已核对”或“看不清”状态。
- 原图与官网资源均不进入正式应用。
