# 展会数据核对记录

底图来自 WF 官方在 B 站动态中发布的 W1—W5 图片，保存在 `public/maps/`，未改写图中文字。W1 图片尺寸为 800×1500，W2—W5 为 800×1480；图面坐标仅用于当前固定底图，不代表实地米数。

各馆展位数据分别维护在 `src/data/exhibition/w1.ts`—`w5.ts`，公共展位类型和数据转换函数位于同目录的 `types.ts`、`helpers.ts`。

目前手工标注 W5 的 39 个编号区域。其中 38 个企业展位的名称依据本届“企业参展商”名录录入；A13 为底图中的官方专区，不在该分类名录中，保留原展位 ID 和名称。W2—W4 已补充清晰可辨的企业展位名称和区域；W1 已录入底图主分区及个人展商图中可确认的细分记录，W2 已补充 J/K/L/M 区个人展商记录。

W1 的 58 个矩形边界已基于 800×1500 固定底图逐项复核；W2 的 78 个矩形边界，以及 W3、W5 各 39 个矩形边界，均已基于 800×1480 固定底图逐项复核。边界以底图中白色展位卡片的可见外沿为准，只调整 `x`、`y`、`width` 和 `height`，未改变展位 ID、名称和检索词。

## 个人展商录入说明

- M1 等主分区是地图点击、定位和照片关联的最小区域；周围的 `01`、`02` 等个人展商编号作为区域内部记录保存，不拆成重叠的点击区域。
- 详情按 `01-展商名` 的格式逐条显示个人展商；搜索命中个人展商后仍定位到所属主分区。
- 无法辨认的名称保留编号和空名称，暂不展示也不参与搜索，避免后续补录时其余编号错位。

## W5 名称录入说明

- 名录黑色栏中的展商名称为主要依据；同一展位的多个名录项合并到同一个名称集合。
- 底图或名录 logo 中清晰可辨、且有利于搜索的中英文别名一并保留，例如 `BEASTBOX`、`HIYA`、`KAIYODO`。
- 中英文组合名称按名录原样用于展示；独立英文名、中文全拼和拼音首字母放入隐藏的 `searchTerms`，不在结果卡片或展位详情中重复显示。
- A31 的三个名录项均标为 `Otherwhere`，另收录清晰可辨的 logo 名称 `CALIBRE` 和 `ASTRANCE`；不重复保存相同名称。
- 不根据编号连续性补造展位，不因企业名录未列出 A13 而删除底图中实际存在的官方专区。

## 待核对资料

- 后续仅在获得更清晰资料时补充仍缺失的 W1—W2 个人展商名称和细分展位编号；难辨内容保持缺失，不猜测补齐。
- 更新资料时保留已有展位 ID。
