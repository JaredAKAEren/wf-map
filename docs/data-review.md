# 展会数据核对记录

底图来自 WF 官方在 B 站动态中发布的 W1—W5 图片，保存在 `public/maps/`，未改写图中文字。W1 图片尺寸为 800×1500，W2—W5 为 800×1480；图面坐标仅用于当前固定底图，不代表实地米数。

目前手工标注 W5 的 39 个编号区域。其中 38 个企业展位的名称依据本届“企业参展商”名录录入；A13 为底图中的官方专区，不在该分类名录中，保留原展位 ID 和名称。W1—W4 仅提供原图，尚无可搜索数据。

W5 的 39 个矩形边界已基于 800×1480 固定底图逐项复核。边界以底图中白色展位卡片的可见外沿为准，只调整 `x`、`y`、`width` 和 `height`，未改变展位 ID、名称和检索词。

## W5 名称录入说明

- 名录黑色栏中的展商名称为主要依据；同一展位的多个名录项合并到同一个名称集合。
- 底图或名录 logo 中清晰可辨、且有利于搜索的中英文别名一并保留，例如 `BEASTBOX`、`HIYA`、`KAIYODO`。
- 中英文组合名称按名录原样用于展示；独立英文名、中文全拼和拼音首字母放入隐藏的 `searchTerms`，不在结果卡片或展位详情中重复显示。
- A31 的三个名录项均标为 `Otherwhere`，另收录清晰可辨的 logo 名称 `CALIBRE` 和 `ASTRANCE`；不重复保存相同名称。
- 不根据编号连续性补造展位，不因企业名录未列出 A13 而删除底图中实际存在的官方专区。
